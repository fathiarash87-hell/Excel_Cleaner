# تمیزکاری خودکار فایل اکسل

یک اسکریپت پایتون که یک فایل اکسل خام و نامرتب را تمیز می‌کند، یک گزارش خلاصه می‌سازد و خروجی را فرمت‌بندی می‌کند.

## امکانات

- پاک‌کردن فاصله‌های اضافه و یکسان‌سازی حروف (`first_name`، `last_name`، `City`)
- حذف ردیف‌های تکراری بر اساس ترکیب نام و نام خانوادگی
- تبدیل ستون `Salary` به عدد و پرکردن خانه‌های خالی
- ساخت گزارش خلاصه‌ی هر شهر (تعداد، میانگین، کمینه، بیشینه)
- ذخیره‌ی خروجی در `clean.xlsx` با دو شیت:
  - **Clean**: داده‌ی تمیزشده
  - **Summary**: خلاصه‌ی هر شهر
- فرمت‌بندی هدر، تنظیم عرض ستون‌ها و ثابت‌کردن ردیف اول

## نیازمندی‌ها

- Python 3.8 یا بالاتر
- کتابخانه‌ها:

```
pip install pandas openpyxl
```

## ساختار پروژه

```
Excel_Cleaner/
├── data/
│   └── raw.xlsx          فایل خام ورودی
├── excel_cleaner.py      اسکریپت اصلی
├── clean.xlsx            خروجی (بعد از اجرا ساخته می‌شود)
└── README.md
```

## نحوه اجرا

1. فایل خام را با اسم `raw.xlsx` داخل پوشه‌ی `data` بگذارید. ستون‌های لازم: `first_name`، `last_name`، `City`، `Salary`.
2. اسکریپت را اجرا کنید:

```
python excel_cleaner.py
```

3. فایل `clean.xlsx` کنار اسکریپت ساخته می‌شود.

## مثال

قبل از تمیزکاری:

| first_name | last_name | City | Salary |
|---|---|---|---|
| ali | rezaei | Tehran | 5000 |
| Sara␣ | ahmadi | tehran | 6200 |
| ali | rezaei | Tehran | 5000 |
| Reza | karimi | Shiraz | (خالی) |

بعد از تمیزکاری:

| first_name | last_name | City | Salary |
|---|---|---|---|
| Ali | Rezaei | Tehran | 5000 |
| Sara | Ahmadi | Tehran | 6200 |
| Reza | Karimi | Shiraz | (میانگین) |

## نکته

اگر هنگام اجرا خطای `PermissionError` دیدید، فایل `clean.xlsx` را در اکسل ببندید و دوباره اجرا کنید.
